TRY THE WINDOWS PREVIEW

Start with
the source.

Build the desktop app, or package the shared canvas for VS Code and Antigravity IDE.

You will need Node.js 22+, Rust (MSVC), Git, Visual Studio C++ build tools, and WebView2. Full setup guide

PowerShell 
git clone https://github.com/onyxfuzzx/AgentCanvas.git
cd AgentCanvas
npm ci
cargo install tauri-cli --version '^2' --locked
npm run desktop

This starts the native desktop app. Install and sign in to your agent CLIs separately.
