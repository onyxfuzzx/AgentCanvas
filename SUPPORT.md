# Getting help

Start with the [setup guide](docs/DEVELOPMENT.md), [user guides](docs/README.md), [editor guide](extension/README.md) and [known qualification limits](docs/PROJECT-STATUS.md).

Current native builds target local Windows x64. Browser development previews do not provide native terminals. Linux/macOS, remote editor windows and hosted execution are planned work.

For a reproducible defect, use the [bug report form](https://github.com/onyxfuzzx/AgentCanvas/issues/new?template=bug_report.yml). Provide the source commit/app version, Windows and editor version, relevant CLI versions, minimal steps, expected/actual behavior and a short sanitized error. Reproduce with a disposable workspace when possible. Never attach real workspace folders, recovery files, credentials or complete terminal/agent transcripts.

Use the [feature form](https://github.com/onyxfuzzx/AgentCanvas/issues/new?template=feature_request.yml) for a concrete workflow improvement. Search existing issues and the [roadmap](ROADMAP.md) first. Usage discussions can move to GitHub Discussions once maintainers enable it; this repository does not assume that setting is already active.

Report vulnerabilities using [SECURITY.md](SECURITY.md). Community support has no service-level guarantee.
