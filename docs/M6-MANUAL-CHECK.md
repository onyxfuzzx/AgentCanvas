# M6 desktop acceptance check

Run `artifacts/windows-debug-m6/agent-canvas-desktop.exe` with its two helper executables alongside it. Use a new workspace named **M6 verification** for these checks. The user confirmed basic page loading and alignment while dragging/resizing/zooming; the deeper checks below remain pending until their results are recorded in VERIFICATION.md.

1. Select **Browser**. Confirm it starts paused. Enter an HTTP(S) URL you intend to visit (a local development server is supported), select **Open**, and confirm the actual page appears. Follow a link, use Back/Forward/Reload, type into a harmless page input and scroll inside the page. The node's toolbar and close/resize controls must remain usable. Tab between the address bar and page; click the canvas before using canvas shortcuts.
2. Move and resize the node, pan it partly beyond each canvas edge, then off-screen and back. The page should clip at the canvas boundary without reflowing just because an edge is clipped. Test 25%, 100% and 200% canvas zoom. Drag the corner at each zoom and confirm the viewport really resizes. Use the minimap and canvas controls while a page lies behind them.
3. Overlap a second browser, a terminal and a note. Bring nodes forward/back and drag headers; pages must not cover higher nodes or their controls. Open Help, Manage workspaces, New terminal and Links while a browser lies behind them. The dialogs/panel should remain readable and clickable. Space-to-pan and whiteboard drawing should temporarily hide page surfaces, then restore them.
4. Stop a page and reopen it. Close a browser node and undo; the restored node should be paused. Open eight pages and verify a ninth Open reports the limit; stopping one should allow the ninth. Switch workspaces and back: all browser nodes should restore paused. Close the app normally and relaunch: the last submitted address/layout should remain, with no automatic page loading.
5. Try `file:///C:/Windows/win.ini`, `javascript:alert(1)`, `data:text/html,test`, `http://ipc.localhost`, and a URL containing embedded credentials. Open should reject them. A test page's `_blank`/window.open and download attempts must not open windows or save files. Camera/location/notification requests must not grant permission. Do not bypass any browser security warning.
6. If available, move the window between monitors with different display scaling. Confirm page position, clipping, text and mouse hit testing after the transition. Check minimize/restore and maximize/restore. Record tested Windows/WebView2 versions and any focus, flicker or clipping problems.

Automated coverage separately verifies URL/payload bounds, workspace roundtrips, occlusion geometry, fractional-DPI rounding, command ordering/coalescing and the native IPC guard with Tauri's mock runtime. It does not replace these visual checks.
